# Put this on GitHub — browser only

You need a GitHub account and a browser. No git, no terminal.

## 1. Create the repo

1. Log in at https://github.com
2. Top right **+** → **New repository**
3. Name, for example: `blake2b-split`
4. **Public**
5. **Create repository**

The address becomes:
`https://github.com/YOURNAME/blake2b-split`

## 2. Upload the files

1. In the new repo: **Add file** → **Upload files**
2. Drop these:

```
README.md
guide.md
GITHUB.md
cards/card-en.png
```

Keep `card-en.png` inside a `cards` folder if GitHub lets you. If the site flattens the upload, put the png next to `guide.md` and fix the README link.

3. **Commit changes**

## 3. Links to paste in Discord / X

Replace `YOURNAME` and the repo name.

| What | Link |
|---|---|
| The repo | `https://github.com/YOURNAME/blake2b-split` |
| The guide | `https://github.com/YOURNAME/blake2b-split/blob/main/guide.md` |
| The image (Discord can embed this) | `https://raw.githubusercontent.com/YOURNAME/blake2b-split/main/cards/card-en.png` |

Discord / X text:

```
One coin, two chains. Spend Blake2b first. The send screen must show 0x21.
https://github.com/YOURNAME/blake2b-split/blob/main/guide.md
```

Attach `card-en.png` in the same post, or paste the raw image link under the text.
