# One coin, two chains

If you held bitcoin before block 961,640, that coin now exists on Bitcoin **and** on the Blake2b Knots chain.

A normal send moves both. This note is how to move the Blake2b copy first without dragging the bitcoin with it.

- Guide: [guide.md](guide.md)
- Card for Discord / X: [cards/card-en.png](cards/card-en.png)
- How to publish: [GITHUB.md](GITHUB.md)

Not financial advice. Test with a tiny amount. If you had no bitcoin before the fork, there is nothing to claim.
